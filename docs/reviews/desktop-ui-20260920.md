## 已检查的界面与边界

- 门户：匿名/登录后入口与个人入口；登录完成后模块可见。
- 交易总览：指标、图表、导航首屏。
- 交易管理：状态筛选、金额排序，确认两条待确认记录按金额排序；桌面表格。
- 交易流程：普通态、询价展开、编辑模式、节点编辑面板打开/关闭；没有保存配置或修改完成状态。
- 管理我的：资料、邮箱、密码、偏好表单布局；没有保存或发送邮件。
- 管理权限：组合搜索/范围选择、空结果、恢复结果；本地追加浏览器回归。
- 管理通知：联系信息、订阅矩阵、设备入口；没有订阅或开启系统通知。
- 融资仪表盘：生产首屏指标与筛选区。
- 市场热点：生产页面内容与控件树已读取，详情交互尚未完成。
- 市场点评视觉/文字版：初轮审查发现窄桌面内容裁切，需要主代理继续确认并修复。

## 后续优先级

1. 市场点评：复核一级发行/二级行情窄列裁切、指数名称省略；保留已确认报告布局与导出约定。
2. 融资仪表盘：监管面板撑高同排两张指标卡，首屏空白过多；检查与项目、额度、日历的阅读顺序。
3. 交易流程：桌面询价金额占位文字偏窄，编辑面板开启后主图的可达性继续复查。
4. 逐页补齐政策/跟踪点评、研究辅助、二级池、融资模型、授信各页、融资项目/SOP/客户/投资人/数据/负债周报、新闻研报详情和资金日报。
5. 管理后台仅管理员可访问的页面需隔离组件场景；测试账号的不可访问状态不冒充页面视觉验收。

未经实际检查的页面和副作用操作不记为通过。用户后续要求停止子代理，后续检查、修复与交付由主代理直接完成。
