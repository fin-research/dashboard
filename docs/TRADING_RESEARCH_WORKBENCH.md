## 统一业务口径

### 交易

- 纳入范围仅为“同业拆借（纯信用）”和“拆出（质押式回购）”。质押式回购融入不计入该工作台交易范围。
- 金额统一使用亿元，接口传输建议使用字符串形式十进制数或最小货币单位，前端不得以二进制浮点作为账务事实来源。
- 利率字段使用百分数值，例如 `1.85` 表示 `1.85%`；利率变动使用 bp。
- 当日成交加权利率：`sum(amount_yi * rate_pct) / sum(amount_yi)`。
- 纯信用占比：`同业拆借成交金额 / 纳入范围成交金额`。
- 对手集中度按纳入范围内的当日成交金额聚合；生产接口需返回用于复核的分母、排名和统计日期。
- 待确认仅表示业务状态，不等于失败或风险处置完成。

### 授信

- 一览表保留“授信一览表”全部机构；周报口径取“授信周报”Sheet 的机构名单。两套口径分别聚合并在 API 中同时返回，不能用固定调整数互相换算。
- `available = total - used`；`utilization_pct = used / total * 100`，`total = 0` 时使用率为 `null`，不得除零后展示为0%。
- 总额、已用、可用和使用率的聚合只纳入 `approved`；空状态在导入时规范为 `revoked`。
- 周报指标固定为授信总额、已用额度、可用额度、新增授信家数和到期家数。新增授信家数只统计本期新增事件；到期包含授信到期和撤销事件。
- 本周授信快讯按编号展示相邻报表日之间的新增、续作、扩额、到期和撤销事件；同一机构同时续作和扩额时只记扩额，分项额度变化及使用额度变化本身不生成事件。
- 近期新增授信批复以所选报表日为截止日回看六个自然月，包含新增、续作和扩额事件，并展示事件发生时的起始到期日、授信总额和授信分项。
- 周报附表列出当前周报名单内已获批机构的总额度、可用额度和使用率，相同银行性质使用合并单元格。
- 授信快讯的跨期金额比较使用两期台账实际总额；上期未获批、本期已获批时不得把上期金额置为 0，仅排除两期都未获批的机构。
- 日历事件分为到期与新增；新增包含生效、续作和扩额，事件同时返回待生效、已生效、待到期、已到期或已撤销状态。
- 缺失到期日保留为 `null`，不得伪造日期。

### 授信导入与存储

- 本地解析命令必须显式传入 `--date YYYY-MM-DD`；不得使用 Excel 中会随打开日期变化的公式单元格推断报告日。
- 数据粒度是报告日。`credit.institution` 保存机构记录，`credit.item` 保存标准化细项，`credit.institution_event` 保存相邻报表日的规范事件与分项快照。
- 不建立业务导入审计表、汇总表或导入批次历史。同一报告日期在 advisory lock 和单事务内先删除再重建机构与分项记录，并重算事件表；其他报告日的机构和分项不受影响。
- 详情修改通过 `PATCH /api/credit` 自动保存，服务端只更新传入的增量字段并在同一事务内提交。

### 研究

- 研究快照必须包含来源、文件哈希或上游批次 ID、统计区间、生成方式、规则版本、校验结果和复核状态。
- 利率值使用百分数值，变动使用 bp；曲线必须带期限和观测日。
- 当前研究底稿未覆盖的 SHIBOR 曲线、逐日 OMO、政策原文、国内高频和海外市场数据均应明确返回 `available: false` 与 `reason`，不得用模拟数字进入正式快照。
- 规则模板输出不等同于大模型输出，也不等同于研究岗已复核结论。

### 交易流程

- `/trading-research/workflow` 为交易流程页，沿用工作台导航。拆借、逆回购每日默认启用，交易所回购每日默认折叠；共通节点不属于流程，共用一份进度，不重复计入三品种。
- 交易流程使用 Svelte Flow，顶部拆借、逆回购、交易所回购为分类项，不作为节点、不连线，保留品种浅色底框，文字居中，不设归档按钮。桌面右侧纵向排列三条流程的横文字标签，手机在画布顶部横排，点击切换展开/折叠；剩余品种重排填满工作区，过渡为 240ms，减少动效时关闭。询价分别位于各品种下方，点击展开可编辑表格，不参与完成状态和待办提醒；按账号、上海自然日和原节点 ID 保存记录，旧记录兼容。
- 拆借询价字段为对手方、交易员、期限、金额（亿）、价格；逆回购省略交易员，价格为实际利率。无表头；期限、金额和价格聚焦后显示前行有效值候选，首项为最近前值，仅 Tab/点击确认后填入，留空与删除不会自动回填。Tab 选中候选并前移，末格 Tab/Enter 校验后进入下一行或追加新行，Shift+Tab 返回。输入首个值不追加空行；每行底线右端附近浮现圆形加号，点击在该行下方插入。鼠标拖动或 Shift+方向键选择矩形单元格，Ctrl/Command+C 复制 TSV，Delete/Backspace 清空选区，整行清空自动移除；Ctrl/Command+Backspace/Delete 删除当前记录。数值在失焦和前移时校验，期限须为有效正整数天数、金额大于零、价格为有效数值，错误保留输入并明确标记。行增删和选项使用短过渡并尊重减少动效。输入即时保存在本地；名单按账号跨日期维护，支持汉字、拼音首字母及部分匹配。旧 notes 内容保留为原询价记录，不强行结构化猜测。
- 拆借价格数字为 SHIBOR 下浮 BP，失焦显示期限天数、金额亿及负 BP；每天上海时间 11:00 后请求 `/data/chinamoney/shibor`，发布前/失败每 15 秒重试，当日完整数据每 5 分钟刷新，后台页面暂停。仅当日已公布利率参与计算（利率百分数减 BP/100），选择不短于询价天数的最短标准档位：1/7/14/30/90/180/270/365 天，超过 365 天继续 BP 报价；不使用昨日利率代替。原 BP 保留，焦点进入价格格时仍编辑数字。
- 节点按显式归属展示，不按同名自动合并；衡泰补单审批分别属于各流程，进度与编辑彼此独立。共通节点独立于三条流程，品种折叠不隐藏共通节点；有流程节点介于共通节点之间时不添加共通节点直连。条件分支的子节点在右侧独立列展开，主流程继续向下，展开不把后续主流程节点向下挤移。同级分支子节点使用品种色浅边框归组；节点、连线和组框同步进行 240ms 滑入淡入与收回淡出，收回结束后卸载，减少动效时直接切换。主干明确使用底部中心出口、顶部中心入口，只有分支首条连线使用左右侧出口。
- 未完成节点白底，品种标签保留浅色底；完成节点使用加深的原语义色，图标不变。分支全部后代任务（含折叠子分支）完成后才着色。顶部时钟每秒显示上海时间，时间轴全长蓝色，淡水平线按显式时点插值并从节点下方穿过。移除 Flow 标识。
- 编辑模式下直接拖动节点调整位置，点击节点打开右侧编辑面板；拖动不改变业务顺序及分支关系，无拖动按钮。偏移量相对自动布局保存于配置的可选 offset 字段，分支展开后仍跟随布局；面板数字字段提供键盘与单指操作替代。询价输入框可通过可选 inquiry 字段配置，既有询价节点兼容旧配置。分支及品种的编辑预览不修改当日激活状态，取消编辑不保存配置；保存失败保留草稿。
- 节点配置包含稳定 ID、归属、上级分支、任务/分支类型、名称、业务内容、开始/结束时间、可选 Lucide 图标键与数组顺序。旧配置缺少图标时沿用默认语义图标；编辑面板内置图标选项。上级只能为同品种分支，禁止循环且最多四层；删除需确认，仅删除选中节点，将直接子节点按原顺序接到原上级并立即保存；失败保留草稿和保存入口。排序针对同级节点，子树随父节点展示。
- D1 `trading_workflow_config` 只存单份共享配置及版本；migration `1015_trading_workflow_config.sql` 播种用户指定的全部节点。只有配置保存会写数据库，不存每日日期、完成状态、分支选择、提醒记录、用户任务或审批审计。
- `GET /api/trading-workflow/config` 要求 `research.workspace:read`，返回 `version/nodes/actorKey/canEdit`。`PUT` 要求 `research.workflow:update`、同源及严格 Schema，且只接受 `{expectedVersion,nodes}`。条件 UPDATE 原子增加版本；冲突返回 409，编辑草稿留在画布与侧面板，取消后可刷新配置。
- 本地 key 按当前账号与上海自然日隔离；新的一天恢复默认品种、空进度和未激活分支。刷新/同账号同浏览器标签页使用 localStorage 恢复，同步 storage 事件；更换浏览器或设备不共享进度。本地存储不可用或损坏时保留当前页内状态并通过全局消息报告，不回传后端。
- 分支激活后自动展开，关闭后折叠；父分支关闭时后代不计入待办、不触发提醒，但本地勾选保留，重新激活时恢复。业务触发条件由经办人选择，时间流逝不会自动确认成交、审批或完成任务。
- 明确时点到点提醒；时间区间在开始与结束提醒未完成节点。晚打开页面或休眠恢复后补报当天逾期未办，已过整个区间只报结束时间。完成或停用品种/分支不提醒，去重粒度为账号、日期、节点、提醒时点与渠道；支持 Web Locks 的浏览器串行领取通知，其他浏览器采用 localStorage 与 Notification tag 尽量去重。
- 提醒权限只在点击按钮时申请；浏览器选择单独保存在本地。支持的桌面浏览器通过 Notification API 弹出通知，不支持/拒绝/发送失败时保留全局消息及待办状态。关闭流程页、浏览器休眠/后台限速或系统禁止通知时无法保证准点送达，不使用服务端推送、邮件或群消息。
- header 只显示实时时钟和编辑模式；内容区无小标题、完成统计、定位/刷新/缩放等工具栏。保存、增加、删除和布局恢复仅在节点编辑面板。
- 左侧时间线使用可见节点的显式起始时间作为锚点，时间游标每秒随上海时钟在锚点间插值；重复时间合并，非递增时点不作为坐标锚点，不给无时间节点创造期限。节点标题使用 1.125rem 粗体，备注使用 0.875rem 普通字重与次级文字色，按自然高度渲染，禁止 fitView 压缩整图；较长流程通过内容区自然滚动，窄屏仅画布局部横向滚动。节点最大宽度 460px，列内居中；相邻节点保留至少 76px 垂直间距。同一目标的入边共用目标上方的水平汇合线，节点实测高度变动后重排并更新连线。

## 数据分层

浏览器不得直连数据库、Choice EDB 或 DM。授信和研究辅助均由 dashboard Worker 通过 Hyperdrive 读取 Neon，其中研究辅助只读 `public.edb`。上游数据只在首次本地回填和每日定时增量任务中调用；其余尚未接入的迁入模块未来仍通过明确的服务端接口读取。

建议逻辑数据域如下，物理数据库与 schema 需在后续接口设计时由数据所有方确认，不能复用或交叉写入 dashboard 现有 Neon `bond`、`financing_model` schema：

| 数据域 | 逻辑实体 | 必备主键/版本 |
| --- | --- | --- |
| 交易 | `trade`, `trade_collateral`, `trade_status_event` | `trade_id`, `version`, `event_id` |
| 授信 | `credit.institution`, `credit.item` | `report_date`, `institution_name`, `item_type`, `updated_at` |
| 研究 | `research_snapshot`, `market_observation`, `curve_point`, `source_availability` | `snapshot_id`, `series_code`, `observation_date` |
| 交易流程配置 | `trading_workflow_config` | 单例 `id=1`, `version` |

授信日报按日期保存，同日更正直接事务替换，不另建导入审计记录；其他业务域若需要不可变历史，应在各自契约中独立设计。列表接口必须稳定排序并返回明确报告日期。

## API 契约

已实现的授信读接口：

- `GET /api/credit`：读取最新报告日。
- `GET /api/credit?date=YYYY-MM-DD`：读取指定报告日；同时返回上一可用报告日、两套汇总、机构数据、两类周环比变动和预警。

研究辅助已实现接口：

## 接入顺序与验收

1. 授信先以 Excel 日报导入作为事实来源，逐项核对两套汇总、机构数量、细项合计、周报名单和阈值结果。
2. 投资人及业务明细进入数据库后，再设计自动占用归集与未匹配告警；不得把当前 Excel 数字与未来自动归集结果混为同一口径。
3. 交易接入前确定数据所有权、权限和 `/data/trading-research/*` OpenAPI/Schema；需保留 `GET /data/trading-research/trades?date=YYYY-MM-DD&query=&product=&status=&cursor=&limit=` 契约。
4. 研究数据首次通过本地全量命令回填，随后由每日增量 Cron 更新；新增或替换指标时先复核名称、ID、单位、频率、区域和展示换算，并同步指标映射测试。任何调试不得用页面挂载或循环请求验证付费 EDB。
5. 交易流程验证配置 Schema、版本冲突、本地跨日隔离、分支启停、通知去重及权限边界。

正式验收至少核对：交易汇总与明细求和一致、授信总额勾稽一致、研究曲线日期一致、流程版本冲突可见、所有页面显示明确基准日、移动端仅表格区域横向滚动。
